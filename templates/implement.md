1. Read the files listed above before writing anything.
2. Find the closest existing example of this kind of code in the repository and follow

## Definition of done

- The change is complete and self-consistent — no TODOs, no stubs, no placeholder values.
- Every file you touched is in the allowed list above.
- Existing behaviour that was not part of this task still works.
- You did not run git commit, git push, or delete any file.

If you could not finish, say exactly what is incomplete and why. A partial change that is
honestly reported is far more useful than a complete-looking one that hides a gap.
